水下网具状态监测：结论一页看懂 范围已收窄：只做「状态监测」，清洗（方向2）整体移出 ｜ 2026-09-24

造一台能逐跨自主到位的监测机器人，沿浮纲展开一张 2.5D 网系地图， 把每张平网上的 侧向间隙、底部间隙、缺块/破洞、网绳变形标进格子。
只测平网，不钻网兜（清洗才是洗兜，那是另一件事）｜ 不洗网 → 不需高压射流、不需泵站、不会自己制造浑浊 → 部署岸基。

1现场到底是什么样的

顺着水流方向看的断面。点下面的标记看每一项在测什么。
① 网缝
侧向间隙
平网边缘与桩之间漏拦的缝。课题组自己在立面图上红框标注的参数——这是客户已经认的验收量。
② 网缝
底部间隙
底纲离渠底/底板多高。基准面是泥面、抛石还是底板，客户必须给。
③ 破损
缺块 / 破洞
网衣上少了的部分和孔洞。注意面积误差 = 尺度误差 × 2；旧网期被附着物糊住，检出率会低。
④ 变形
网绳变形
网体被流拉出鼓包/偏斜、纲绳离位、网缘脱桩。柔性网天生会动，要区分"正常变形"和"失效变形"——这是本方向最难的判定。

刚撤回的一个错 我一度说本现场是「3+n 三道网」（W1 粗平网 / W2 中目 / W3 细目网兜）， 来源只是资料包《02_literature.md》里一行二手转述，说的是一篇设计论文。 对照课题立面图、俯视图和现场照片后确认：本现场是一道平网 + 一排网兜，只有一道。 侧隙只在平网上测，网兜不测侧隙 —— 所以工作量比原先估的还少，不是多。

2通读全部资料后：六项更正 + 一项范围再收窄

13 个月的现场照片 + 课题 PDF 内嵌图，改掉了之前基于少量材料做的几个结论。
已撤回「三道网」是错的 —— 现场是一道平网 + 一排网兜
我之前说错按资料包《02_literature.md》里一行二手转述（熊碧露 2022 论文的「3+n：W1/W2/W3」），说本现场有三道网、侧隙要测三次、工作量乘 3。
一手材料课题立面图：每跨就一张网，高 9200，挂两桩之间；俯视图：一排网兜；照片里就是一排兜，每兜跨两柱。侧隙只在平网上测。「3+n」是设计论文的写法，不是本现场实测。
范围再收窄兜不测 —— 机器人不进网兜，也不钻到兜里去
我一度想测兜形倾角（规范 ≥70°）、兜内堵塞、兜尾状态。
现在网兜结构本身就会挡住里面的东西，而且形状是软的、会鼓，机器人进去既看不见也出不来。监测只做平网：缝、缺块/破洞、网绳变形。清洗才是洗兜（那是方向2，不在本范围）。
更正 2浊度不是常数，存在真实清水窗口
之前默认"全浑浊、视觉不可见"，方案被动分级应对。
现在2026-04-26 那组照片里，水是绿的、清的、能看清水下网体；而 2024-08 / 2025-12 是棕褐不透明。策略改为：主支排程等清水窗口，声呐+接触兜底。
更正 3"全浑浊"是方向2 自盲的结论，不是方向1 的常态
之前把"浑浊到视觉不可见"当成本题环境前提。
现在浑浊是清洗自己制造的。方向1 不洗网、不射流、不搅底泥，遇到的是自然浊度，而自然浊度会随季节/潮汐变化。这是范围收窄换来的最大红利。
更正 4桩比三维模型大得多
之前3D 模型用底径 1.4 m 圆柱桩。
现在照片里是大直径混凝土圆柱 + 很厚的承台梁，目测 1.5–2 m。这是好消息：桩越大，特征越可测——用桩当标尺、当声呐目标、当接触基准，都比设想中容易。
更正 5跨数第一次能数出来
之前不知道一个厂址有多少跨，工期无法估。
现在从全景照片数柱：每个结构约 8–10 跨；结合文献（红沿河 580 m / 14 段）→全厂约 10–30 跨。方向1 最需要的工程量参数，终于有了。

3没有里程计，怎么知道自己在哪

柔性网会变形（环境非静态）＋ 推进器驱动（无轮式里程计）＋ 浑水无特征点 → SLAM 三个前提全破。替代方案：不建网面图，只建台账。

课题图纸俯视图的连续尺寸链

18000  |  16000  |  18000  |  16000  |  18000  |  16000

跨距不是常数，是两种节距交替。这同时否掉了一个思路、又给了一个更好的：

否掉"数桩 × 固定节距"推累计距离——等距假设从第 3 跨起累积半个节距（1 m）误差。
改用用节距的交替模式本身做跨号签名。比数桩更鲁棒，因为节距本身携带跨号信息。

三层拓扑：L1 道 → 跨 → 缝 → 兜（全局身份）｜L2 每跨内部覆盖｜L3 跨相对导航。桩的探测：接触缓冲（最可靠，主用）→ 成像声呐 → 光学窗口（仅清水期校验）。

棕绿水，网兜轮廓隐约可见；同时拍到黄色模块化浮排平台（带走道、设备、上岸坡道）——这就是课题里"水面清理平台"的实物参照。

2025-12-09 / 12-17
棕褐、浑。全景可见成排网兜挂在相邻柱之间（可数出约 8–10 跨），并拍到黄色收放网门吊与甲板绞车。
2026-01-06
水浑，但网是灰白色新网——看起来刚换过。
2026-04-26
绿、清，能清楚看见水下网体和兜。网呈白色/米色 = 新网。这是光学测量可行的直接证据。
2026-07-16
拍到堆场上大量换下来的旧网（深褐、附满海生物）——印证文献里"细目网以换代清"。同时说明：旧网期的破损检出率会明显低于新网期。
结论 浊度会变，策略就该跟着变：主支是排程等清水窗口集中作业；声呐 + 接触缓冲作兜底；浊度计全程记录，让每条数据都带可信度标注。
必须写明的能力边界：全浊期侧隙可测（接触限位），破损不可测。任何声称"全浑浊也能识别破损"的方案，都是在赌客户不懂水。

6拆成三个问题（对回你 GitHub 仓库的任务拆分）

反着从 docs/tasks/01·02·03 推回来：这三件事合起来才是"机器人对网的监测"。
任务 1 · mapping
2.5D 网系地图
沿浮纲把网面展开成栅格：横轴 = 第几道第几跨，纵轴 = 水深。
每格记：离网距 d、离底距 h、污损、可观测性。
特殊地形写进格子：道、跨、缝、洞、底隙。
关键：跨号来自桩距先验，潮位变、d/h 变，跨号不能变。看不见的格子标 unknown，不虚报洞。
任务 2 · vision
低能见度识网
浑水低照下仍要看清网结、纲线、孔，给地图提供孔级观测。
两步：水下图像恢复（UIE，去散射纠色）→ 结节/纲线/孔分割。
视觉不负责全局定位，只负责"这一格我看到什么"。
浊度过高直接输出"本格不可观测"，不硬猜。
任务 3 · self-state
自身与网的关系
机器人必须知道自己在哪一跨、多深、离网多远、是否与网平行。
状态 x = (s, z, d, psi)：跨号、水深、离网距、姿态角。
没有这一项，2.5D 地图对不齐——这是贴网行走的前提。
学术名：可变形表面上的相对位姿调节；不是开水域 AUV 导航。

这三个问题对应你原话里的三句话

我是谁自身状态：位姿 (s,z,d,ψ)、是否在作业窗内。
→ 任务 3
我在哪网系定位：2.5D 网图 M(s,z)，不做渠道三维房间图。
→ 任务 1
我看见什么低能见度识网：UIE 恢复 + 结节/孔分割，洞/缝/底隙写进格子。
→ 任务 2

8还卡在客户输入的

前三条不定，技术方案就是空的——它们是客户的运维/安全参数，不该由我猜。
  • 1. 潮位变化到底有多大？ 决定地图能不能用
    任务1 的验收标准是"潮位变了跨号不乱"。可潮位一变，网就鼓、就离底，同一格的 d 和 h 全变。潮差多少、网变形多少，决定 M(s,z) 是建一次就够，还是要按潮位分层建。
  • 2. "实时"到哪一级？ 机上即时出数，还是上岸后出报告？
    决定要板上算力 + 标定链，还是普通观测级 + 后处理。成本分水岭。
  • 3. 侧隙阈值多少算超限？
    决定测量精度需求——±20 mm 与 ±200 mm 是两代产品。
  • 4. 破损面积多大算要换网/补网？
    决定检出下限与相机分辨率。
  • 5. 底缝基准面是泥面、抛石，还是结构底板？
    泥面会随淤积变，底板不变。我倾向底板，但要客户确认。
  • 6. 18000 / 16000 是否真交替？竣工图能否提供？
    跨号先验成立与否；也决定"桩当标尺"用哪个特征尺寸（圆的直径 vs 倒 T 的翼缘宽）。
  • 7. 网绳变形里，哪些算"正常"、哪些算"失效"？
    柔性网天生会鼓会斜，潮位一动形状就变。没有一条失效判据，"变形"这个指标就没法验收——这是四个指标里唯一没有规范依据的。
  • 8. 视频1「网具水下视频」能不能看？
    这是本方向的基准态样例，也是我唯一还没看的一手素材。看了它，浊度分级和检测难度就能定档。
  • 9. 旧网期的破损检出率预期？
    2026-07 堆场照片证明网在以换代清。白网上一个洞极明显，褐网上洞被附着物糊住——不能给一个全期一致的检出率承诺。
