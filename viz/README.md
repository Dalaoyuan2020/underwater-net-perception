# 可视化

三个 HTML，浏览器直接打开即可。GitHub Pages **不渲染 Three.js**，3D 那两个请下载后本地打开。

| 文件 | 内容 | 依赖 |
|---|---|---|
| **`onepage.html`** | **一页总览（推荐入口）**：平面图 → 3D → 检查项 → 三个问题 → 更正记录 → 待确认。顶部吸顶导航可跳 | Three.js（CDN，仅第 2 节） |
| `net-orientation-2d.html` | 纯 2D：平面图（含机器人行走区域）+ 正对迎水面 | 无 |
| `net-perpendicular-3d.html` | 单独的三维模型：桩排 / 垂直帘幕 / 下游网兜，四视角切换 | Three.js（CDN） |

## 看图要点

- **网垂直于水流**成一道帘幕截流；平面图上水流箭头与网线必须正交。
- **网与网兜之间隔开一段**，那一段就是**机器人的行走区域**。
- **只检查平网**（侧隙、底缝、缺块/破洞、网绳变形）；**网兜不检查**，机器人不进网兜。
- 上游水流箭头**不穿过网面**，撞到网前即消失，从上游重新出现。
