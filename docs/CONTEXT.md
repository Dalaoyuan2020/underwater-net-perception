## 1. 方向：这是什么工程问题

滨海核电用海水冷却。海水进厂路径：

```
南海 → 口门 → 港池 / 消浪池 → 明渠 → 沉沙 → 泵房前池
      → 拦污网（本课题）→ 粗格栅 → 细格栅 → 鼓形滤网 → 循环水泵
```

拦污网是格栅和鼓网之前的第一道屏障。电厂怕三件事：**堵**（藤壶/贼贝/水母/毛虾/浒苔/泥糊网目）、**漏**（桩缝/底缝/破洞）、**洗完更糟**（明渠单向进厂，碎渣默认流向泵房）。

「净水网」这里的准确说法是 **冷源取水口拦污/拦截网**，不是凝结水精处理。
课题原文两条曾是监测+在线清洗。本仓库只做监测/感知。

### 2.2 卫星图在看哪 [工作假设]

俯视的是 **泵房前池 / 明渠末段**，不是码头取水，不是口门导流堤。

```
图上方 ≈ 上游（港池 / 口门方向）
        柔性网片被流拉成一排暗色条带
        白黑相间浮筒 + 浮纲 = 一道柔性拦截网
        可见作业小船拐在网上
图下方 ≈ 下游泵房进水口
左岸 ≈ 斜坡护岸
右岸 ≈ 直立岸壁 / 码头弯角
流向 ≈ 上游港池 → 穿过这道网 → 泵房
```

网是柔性的：水面是浮筒和浮纲，水下网衣被流向泵房的水拉斜、鼓包。工作船已经在网上，现状仍是船+人/遥控。

### 2.3 田湾 [对照，非主场地]

江苏连云港田湾核电是另一套：东北向双导流堤 + 长取水廊道，口门约 34.71N, 119.48E。方案已锁定阳江。何刚与某厂对应 **未证实**。

## 3. 环境：这张网长什么样

一道网分成若干跨。课题图一跨约 18 m（示意）。一跨里：桩/承台、上纲+浮筒、柔性平网、有的系统还有柔性网兜、底纲/锚。

特殊地形必须进地图：道、跨、缝（旁路漏拦）、洞、底隙。

和青岛养殖网箱不同：这里是开敞明渠里的柔性帘，下游几米到几十米就是泵房；不能围着网箱转一圈。

水环境：浑、绿、低照；网纹重复；单向流推软管；潮位改变鼓包和离底，跨号不应变。
