# 三条更正（早期判断 → 一手材料后）

这些是被一手材料推翻的早期结论。写在这里是为了后来的人不再犯同样的错。

## 1. 「三道网」—— 撤回

| | 内容 |
|---|---|
| 早期说法 | 本现场是「3+n」三道网：W1 粗平网 / W2 中目 / W3 细目网兜；侧隙每道都要测，监测对象 ×3 |
| 来源 | 资料包里一行二手转述（某设计论文，《中国港湾建设》2022） |
| 一手材料 | 课题**立面图：每跨就一张网**，高 9200，挂两桩之间，无第二三层；**俯视图：一排网兜**；现场照片里就是一排兜，每兜跨两柱 |
| 结论 | **本现场是一道平网 + 一排网兜。**「3+n」是设计论文的写法，可能是某套设计推荐或另一厂址（如岭澳）的做法，**不是本现场实测** |

**连带更正**：
- 侧隙**只在平网上测**，网兜是收污结构，不测侧隙
- 每跨测 1 道平网 + 1 个网兜，工作量按"一道"算，比"三道"估的更少

**教训**：二手转述稿里的条目，未经图纸核实前不能当现场事实。

## 2. 网的朝向 —— 画反过

| | 内容 |
|---|---|
| 早期图 | 网画成沿水流铺开的一片斜膜，桩排在水的两侧 —— 那是**纵向**看，等于网顺着水流 |
| 一手材料 | 课题三维示意图（桩 / 平网 / 网兜 / 水流方向）：平网是**垂直帘幕**，网兜在下游 |
| 结论 | 桩排**垂直**水流成一行，网挂在相邻桩之间形成垂直帘幕截流；网兜在下游、**与网隔开一段** |

**判断对错的唯一标准**：平面图上，水流箭头和网线必须**正交**。若网也画成横线、与水流平行，就是错的。

## 3. 浊度不是常数 —— 「全浑浊」是方向2 自盲的结论

| | 内容 |
|---|---|
| 早期默认 | "全浑浊、视觉不可见"。方案被动分级应对 |
| 照片证据 | 2026-04-26 那组水是**绿的、清的、能看清网体**；2024-08 / 2025-12 是棕褐不透明 |
| 结论 | **清水窗口真实存在**，光学测量可行有照片为证。策略改为主支排程等窗口，声呐 + 接触兜底 |

**连带更正**：浑浊主要是**清洗自己制造的**（射流冲溅 + 剥落物悬浮）。只做监测就不自盲，遇到的是自然浊度，而自然浊度会随季节/潮汐变。

## 4. 桩比三维模型大得多

`net-structure-3d.html` 原用底径 1.4 m 圆柱桩；照片里是大直径混凝土圆柱 + 很厚承台梁，目测 1.5–2 m。
桩越大，作为**标尺 / 声呐目标 / 接触基准**越可测 —— 这一条是利好，不是问题。

## 5. 跨距不等距

早期假设等距 18 m。俯视图尺寸链实为 **18000 / 16000 交替**。
等距假设从第 3 跨起累积半个节距（≈1 m）误差；改用**节距交替模式本身做跨号签名**更鲁棒。

## 6. 范围：网兜不检查

早期想测兜形倾角、兜内堵塞、兜尾状态。现确认**不测**：网兜结构本身会挡住内部，且形状软、会鼓，机器人进去既看不见也出不来。
网与网兜之间那段空间 = **机器人行走区域**。
