## 归纳出的四条

1. **浊度不是常数**：2026-04-26 清水期能看清网体 → **清水窗口真实存在**，光学测量可行有照片为证。
2. **网有新旧两态**：白色新网 / 深褐旧网。白网上破洞极明显，褐网上被附着物糊住 → **旧网期破损检出率会显著低于新网期**，不能给全期一致的检出率承诺。
3. **网在被成批更换**（2026-07 堆场照片），文献"细目网以换代清"得到实物印证。
4. **桩比三维模型大得多**：照片里是大直径混凝土圆柱 + 很厚承台梁，目测 1.5–2 m；原 `net-structure-3d.html` 用底径 1.4 m。桩越大，作为标尺/声呐目标/接触基准越可测。
