## 2. 平网 / 网兜 / 桩 三维示意图

`桩 / 平网 / 网兜 / 水流方向` 四个标注。关系：

```
水流 →  平网（垂直帘幕，迎水面）→  网兜（漏斗形，向下游收拢）→  下游泵房
        侧隙、底缝在这测              不在检查范围
```

- ✅ 平网**垂直**水流，是截流面
- ✅ 网兜在网的**下游**
- ⚠️ 网与网兜之间**隔开一段距离**（用户确认）；这段即**机器人行走区域**，图纸上无此数值，需现场量

## 4. 课题原文（方向1）

> 研究目标：实时监测水下在役网具整体状态，**重点检测网具与构筑物之间的间隙大小**，并识别网具是否存在破损。
> （现有水下状态可参考视频1：网具水下视频）
>
> 初步想法：考虑采用遥控式网具监测机器人，搭载高清摄像设备下潜作业，采集水下图像数据，并基于图像识别技术，自动计算网具与构筑物**侧向、底部**的间隙尺寸，以及识别并**量化**网具破损的**形状与面积**。

措辞权重：原文用"**重点**检测间隙"、"**并**识别破损"——间隙是主指标，破损是副指标。
