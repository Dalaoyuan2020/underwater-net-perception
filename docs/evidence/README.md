## 一句话摘要

- 现场是**一道平网 + 一排网兜**，不是三道网。
- **跨距不等距：18 m / 16 m 交替**；网高 9200 mm。
- **侧隙被课题组自己在立面图上红框标注** —— 这不是外部推断的需求。
- **网垂直于水流**成一道帘幕截流；**网兜在网的下游、与网隔开一段**，中间那段就是**机器人的行走区域**。
- 监测只做平网（侧隙、底缝、缺块/破洞、网绳变形）；**网兜不检查，机器人不进网兜**。
- 浊度**不是常数**：2026-04-26 清水期能看清水下网体，2024-08 / 2025-12 全浊。**浑浊是清洗自造的，不洗就没有这个问题。**
