# 任务 1：网具 2.5D 建图

## 目标

给挂在浮纲上的柔性拦截网建一张 **网系地图**。机器人在这张网上走，不在渠道三维空间里乱跑。

## 地图

沿浮纲拉开网面：

- 横轴 s：第几道、第几跨
- 纵轴 z：水深分段
- 每格标量：离网距 d、离底距 h、污损、可观测性
- 特殊地形写入格子：**道、跨、缝、洞、底隙**

道 / 跨来自桩距先验；缝是两幅网交接的长条异常；洞是局部孔拓扑异常；底隙是最底一排 h 超阈值。

## 像扫地机的地方

扫地机：房间地板栅格 + 沿墙。
这里：网面栅格 + 贴网。网会鼓、会离底，同一跨允许 d,h 随潮位改，跨号不变。

## 验收

- 重复下潜，同一破洞落到同一 (s,z)
- 潮位变了跨号不乱
- 不可见格子标 unknown，不虚报洞

网箱 3D：单目深度 + Wavemap（arxiv 2409.15475）。本任务改成明渠挂网的 2.5D 展开。
