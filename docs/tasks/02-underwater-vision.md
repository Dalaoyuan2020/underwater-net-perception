# 任务 2：低能见度水下视觉

## 目标

让相机在取水明渠浑水、低照里仍能看清 **网结、纲线、孔**，给地图提供孔级观测。视觉不负责全局定位。

## 做什么

1. 水下图像恢复（UIE）：去散射、纠色、提对比
   - 基准：UIEB、EUVP、LSUI、UFO-120
   - 起点：Water-Net；可换轻量网络
2. 网结构分割：结节、纲线、孔
3. 异常：孔面积突变 → 洞；跨间长条 → 缝

## 验收

恢复后的图能被分割模型吃进去。不刷 UIQM 分数。浊度过高输出「本格不可观测」。
